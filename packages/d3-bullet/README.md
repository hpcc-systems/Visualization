# @hpcc-js/d3-bullet

A maintained D3 bullet chart generator for the HPCC Visualization Framework.

This package is based on [GordonSmith/d3-bullet](https://github.com/GordonSmith/d3-bullet), a D3 v4 port of Mike Bostock's original bullet chart plugin. The original implementation is distributed under the BSD 3-Clause License.
