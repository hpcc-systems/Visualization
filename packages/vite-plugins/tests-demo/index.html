vite-plugin-dojo

Dojo 1.x AMD modules, bundled by Vite.

dojo/has!

    dijit widgets

    Custom template widget

    dojox/widget/Toaster

    A DojoX notification widget loaded as a normal AMD dependency.

    dijit on demand

    dijit/Dialog is pulled in by an asynchronous require([…]), so Rollup emits it as its own chunk and it is fetched only when the button is pressed.

    Inlined at build time by the dojo/text! loader extension.
